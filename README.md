# CLIMAPPRENDRE

Schéma interactif pour expliquer le fonctionnement d'une climatisation en formation.

Ouvrir `index.html` dans un navigateur : aucune installation, fonctionne hors ligne.

- Mono-split, multi-split, VRF (réseau en série avec refnets)
- Unités murale, cassette, plafonnier, console, gainable (gaines, zoning, bouches, reprise, portes détalonnées)
- Mode froid / chaud, Rayon X, étiquettes, visite guidée, quiz
- Pannes et erreurs de pose, dégivrage, condensats
- Aide au dimensionnement (W/m³, apports, G × V × ΔT, taux de brassage)
